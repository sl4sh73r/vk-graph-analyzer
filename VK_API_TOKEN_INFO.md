# Информация о токенах VK API

## ⚠️ Важно: Два независимых сервиса

VK ID OAuth (новая система авторизации) и VK API (классический API для данных) — это **два разных сервиса** с несовместимыми токенами.

## Два типа токенов

### 1. VK ID OAuth Токен (`id.vk.com`)

- **Формат:** `vk2.a.XXXXXXX`
- **Назначение:** Современная система авторизации OAuth 2.0
- **Scopes:** `vkid.personal_info`, `friends`, `email` и т.д.
- **Использование:** Идентификация пользователя, получение базовой информации профиля
- **Ограничение:** ⚠️ **НЕ работает** с VK API методами (`friends.get`, `users.get`)

### 2. Service Token / VK API Token (`api.vk.com`)

- **Формат:** строка вида `service_key` или старые user tokens
- **Назначение:** Доступ к VK API для получения данных ВКонтакте
- **Методы:** `friends.get`, `users.get`, `friends.getMutual` и т.д.
- **Использование:** Получение списков друзей, информации о пользователях
- **Ограничение:** ⚠️ Работает только с **публичными данными** (открытые профили)

## Как работает приложение

### Текущая архитектура

Приложение использует **оба токена** для разных целей:

#### ✅ VK ID OAuth токен — для авторизации пользователя

1. Пользователь нажимает "Войти через VK ID"
2. Перенаправляется на VK ID OAuth (через ngrok HTTPS)
3. После успешной авторизации получаем VK ID токен
4. Сохраняем в сессии для идентификации пользователя
5. **Scopes:** `vkid.personal_info,friends`

#### ✅ Service Token — для работы с VK API

1. Генерируется в настройках VK приложения ([id.vk.com](https://id.vk.com))
2. Хранится в `backend/.env` → `VK_SERVICE_KEY`
3. Используется для всех вызовов VK API методов
4. Позволяет получать **публичные данные**:
   - Профили пользователей
   - Списки друзей открытых аккаунтов
   - Фотографии профиля
5. **Ограничение:** не работает с закрытыми профилями

## Ограничения

### ❌ Закрытые профили

**Проблема:** Service token не может получить список друзей закрытого профиля.

**Почему:** Service token — это публичный токен приложения, у него нет прав конкретного пользователя.

**Решение:**
1. Попросить пользователя сделать профиль открытым
2. Сделать список друзей публичным в настройках приватности ВКонтакте:
   - [vk.com/settings?act=privacy](https://vk.com/settings?act=privacy)
   - "Кто видит список моих друзей и подписок" → **"Все пользователи"**

### ❌ Приватные данные

**Что недоступно через Service Token:**
- Личные сообщения
- Закрытые альбомы
- Списки друзей закрытых аккаунтов
- Приватные посты

**Что доступно:**
- ✅ Имя, фамилия
- ✅ Фото профиля
- ✅ Список друзей (если открыт в настройках)
- ✅ Публичные посты

## Почему так?

### Разделение ответственности

ВКонтакте разделил систему авторизации и API для повышения безопасности:

1. **VK ID** — для входа в приложения (OAuth 2.0, современный стандарт)
2. **VK API** — для получения данных (старый API с собственными токенами)

### Будущее

В будущем VK может добавить **обмен VK ID токена на VK API токен** (token exchange flow), но сейчас это два независимых сервиса.

## Альтернативы

### Если нужен доступ к закрытым профилям

1. **Старый OAuth 2.0** (Direct Authorization)
   - ⚠️ Deprecated! Не рекомендуется
   - Выдаёт токены с правами конкретного пользователя
   - [Документация](https://dev.vk.com/ru/api/access-token/authcode-flow-user)

2. **Сделать профиль открытым**
   - Попросить пользователя изменить настройки приватности
   - Самый простой способ для публичных приложений

3. **VK Mini Apps**
   - Работают внутри ВКонтакте
   - Имеют больше прав доступа
   - [Документация](https://dev.vk.com/ru/mini-apps/overview)

## Конфигурация (.env)

### backend/.env

```properties
# VK OAuth App credentials
VK_APP_ID=ваш_app_id
VK_CLIENT_SECRET=ваш_client_secret
VK_REDIRECT_URI=https://ваш-домен.ngrok-free.app/auth/callback

# VK Service Key (для VK API)
VK_SERVICE_KEY=ваш_service_key_здесь

# Backend server
PORT=4000
CORS_ORIGIN=https://ваш-домен.ngrok-free.app
SESSION_SECRET=случайная_строка_минимум_32_символа

# Flood control protection
VK_INITIAL_COOLDOWN_SEC=10
```

**Где взять Service Key:**
1. Откройте [id.vk.com](https://id.vk.com)
2. Выберите ваше приложение
3. Настройки → **Доступ к API** → **Сервисный ключ доступа**
4. Скопируйте ключ

## Итоги

| Токен | Назначение | Формат | Использование |
|-------|-----------|--------|--------------|
| **VK ID OAuth** | Авторизация | `vk2.a.XXX` | Идентификация пользователя |
| **Service Token** | VK API | Строка | Получение данных (friends.get, users.get) |

✅ VK ID OAuth — работает для авторизации через ngrok HTTPS  
✅ Service Token — работает для публичных данных  
❌ VK ID токены НЕ работают с VK API напрямую  
⚠️ Закрытые профили недоступны через Service Token
